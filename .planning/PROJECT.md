# ADERI - Associação de Energias Renováveis

## Objetivo
Criar um site institucional moderno, com design altamente impressionante e tecnológico para uma associação de energias renováveis. 

## Stack Tecnológica
- **Framework:** React via Vite
- **Estilização:** Vanilla CSS
- **Animações e Micro-interações:** GSAP / Framer Motion
- **Metodologia:** GSD (Get Shit Done) guiado por specs.

## Visão de Produto e Design
- **Público-alvo:** Empresas, investidores, e sociedade em geral interessada em sustentabilidade e energia verde.
- **Vibe Visual:** Futurista, clean, tecnológica, verde neon / tons escuros, glassmorphism.
- **Componentes Core:**
  - Hero section impactante.
  - Efeitos de revelação no scroll.
